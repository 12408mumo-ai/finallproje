# Rafna Investment

A responsive React + Vite + TypeScript storefront and Supabase-backed administrator workspace for Rafna Investment, Nairobi.

## Stack

- React, TypeScript and Vite
- React Router
- Supabase Auth, Postgres and Storage via `@supabase/supabase-js`
- Lucide React icons

## Environment variables

Create a local `.env` file in the project root. Only these two public client variables are required:

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

Never put a service-role key, database password or administrator credentials in `.env`, source code or the browser. The application deliberately shows a configuration screen when either variable is missing.

## Supabase expectations

The connected project should already contain the schema and policies described by the project brief:

- `categories(id, name, created_at)`
- `products(id, title, category_id, price, description, image_url, created_at, updated_at)`
- `admins(user_id)`
- public Storage bucket `product-images`
- public read access for products/categories and administrator-only writes

Create the initial administrator in Supabase Auth, then insert that user's UUID into `admins`. The frontend does not create, pre-fill or store administrator passwords.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

`npm run lint` runs the TypeScript project check.

## Application structure

```text
src/
  admin/       Protected layout, route guard and edit modal
  components/  Shared public, form, modal, image and notification components
  hooks/       Auth, toast, product and category hooks
  lib/         Supabase client, errors, business content, validation and WhatsApp helpers
  pages/       Public pages and administrator pages
  services/    Products, categories, storage and authentication data access
```

The public site has Home, Shop and Order Now flows. There is intentionally no cart, search, wishlist or checkout. Orders are sent through the WhatsApp message generated by `src/lib/whatsapp.ts`.
